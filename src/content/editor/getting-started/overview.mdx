构建符合你产品需求且具备你所需功能的富文本编辑器。Tiptap 以现代、框架无关的 API 封装了久经考验的 ProseMirror 库，并为你提供涵盖各种场景的扩展和功能。

## <span data-original-heading-id="what-is-tiptap">什么是 Tiptap？</span>

Tiptap 是一个无头的富文本编辑器框架，让你能够构建完全针对你和你客户需求量身定制的自定义编辑器。
它基于 ProseMirror 构建，这是一个用于在 Web 上构建富文本编辑器的久经考验的库。
底层，Tiptap 高度依赖 [事件](/editor/api/events), [命令](/editor/api/commands)，
以及 [扩展](/editor/extensions/overview) ，以提供构建编辑器的灵活且强大的 API。

## <span data-original-heading-id="why-pick-tiptap">为什么选择 Tiptap？</span>

- **默认为模块化：** 仅添加你需要的扩展，从加粗和链接到复杂的表格和斜杠菜单。保持代码包小巧，并让你的 Schema 处于受控状态。
- **无头优先** 将 Tiptap 集成到 React、Vue、Svelte、原生 JS 或任何其他框架中。或者与 React [UI 组件和模板](/ui-components/getting-started/overview)
- **开源与专业扩展：** Tiptap 的开源版本在 GitHub 上基于 MIT 许可证发布。当你需要如评论或 AI 命令等高级功能时，可以使用付费的 Tiptap 扩展。

想要开始使用 Tiptap？请跟随我们的 [安装指南](/editor/getting-started/install) 来使用 Tiptap 搭建你的第一个编辑器。

### <span data-original-heading-id="extend-your-editor">扩展你的编辑器</span>

通过开源或 Pro 扩展来扩展你的 Tiptap 编辑器。Tiptap 套件增添了更多高级功能，并可通过你的 [Tiptap Cloud 控制台](https://cloud.tiptap.dev/v2/billing).

- 从 [`StarterKit`](/editor/extensions/functionality/starterkit) – 一个内置全套核心标记和节点的套件。
- 添加 [功能扩展](/editor/extensions/functionality) – 字符计数、占位符、历史记录。
- 添加 [内容扩展](/editor/extensions/overview) – 图片、表格、图表、自定义节点。
- 参考我们的 [自定义扩展指南](/editor/extensions/custom-extensions).
